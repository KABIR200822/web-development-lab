Building for the Web

Modern websites use semantic HTML to describe content and CSS to control presentation. Grid is especially useful for two-dimensional layouts because it manages rows and columns together.

Responsive design allows a layout to adapt to different screen widths. Media queries can change the number of columns when the available space becomes smaller.

Quick Guide

Use Flexbox for arranging items in one direction. Use Grid when the design needs rows and columns.
