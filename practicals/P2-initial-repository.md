# P2 – Portfolio Repository and Initial Commit

## Aim
Create a Git repository for the portfolio practicals and record the first version.

## Commands used
```bash
git init
git status
git add README.md
git commit -m "P2: Add initial README"
git branch -M main
git remote add origin https://github.com/KABIR200822/web-development-lab.git
git push -u origin main
```

## Explanation
- `git init` initializes a local repository.
- `git status` displays changed and staged files.
- `git add` stages the README.
- `git commit` records the staged change.
- `git branch -M main` names the main branch.
- `git remote add origin` connects the local repository to GitHub.
- `git push -u origin main` publishes the branch and sets its upstream.

## Result
The `web-development-lab` repository was created on GitHub and the initial README commit was pushed.

## Conclusion
A Git repository was initialized, committed, connected to GitHub and published.
