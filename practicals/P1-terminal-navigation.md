# P1 – Project Folder and Terminal Navigation

## Aim
Create a project folder and navigate to it using the macOS Terminal.

## Commands used
```bash
mkdir -p ~/web-development-lab
cd ~/web-development-lab
pwd
git --version
```

## Explanation
- `mkdir -p` creates the project folder. The `-p` option avoids an error if it already exists.
- `cd` changes the current working directory.
- `pwd` prints the current directory so the location can be verified.
- `git --version` checks that Git is installed.

## Result
The `web-development-lab` folder was created in the user's home directory and opened in Terminal. Git was available for the later practicals.

## Conclusion
The project workspace was prepared successfully using basic terminal navigation commands.
